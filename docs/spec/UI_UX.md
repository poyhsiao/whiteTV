## 1. 視覺美學

### 1.1 設計方向

**方向**: Warm Entertainment + Glass/Frosted
- 暖色調營造家庭客廳溫馨感
- 毛玻璃效果帶來現代精品級質感

### 1.2 色彩系統

| 角色 | 色值 | 用途 |
|------|------|------|
| 主背景 | `oklch(15% 0.02 30)` | 深暖灰，保護 OLED |
| 卡片底色 | `oklch(95% 0.01 60 / 0.7)` + blur | 毛玻璃核心效果 |
| 強調色 | `oklch(75% 0.15 70)` | 琥珀/金色，娛樂感 |
| 次要強調 | `oklch(65% 0.12 45)` | 珊瑚橘，直播/警報/CTA |
| 文字主色 | `oklch(98% 0.01 60)` | 暖白，高可讀性 |
| 文字次色 | `oklch(70% 0.02 30)` | 啞暖灰 |

### 1.3 毛玻璃實現

```dart
Container(
  decoration: BoxDecoration(
    color: Colors.white.withOpacity(0.1),
    borderRadius: BorderRadius.circular(16),
    border: Border.all(color: Colors.white.withOpacity(0.2)),
  ),
  child: ClipRRect(
    borderRadius: BorderRadius.circular(16),
    child: BackdropFilter(
      filter: ImageFilter.blur(sigmaX: 20, sigmaY: 20),
      child: content,
    ),
  ),
)
```

## 2. 導航模式

### 2.1 TV 模式（Android TV / GoogleTV）

- 頂部橫向 Tab 導航（首頁、分類、直播、搜尋、收藏、設定等）
- Tab 順序可在設定頁調整（拖曳排序）
- 底部預覽欄（精選、最近觀看、直播頻道）

### 2.2 Mobile 模式（iOS / Android）

- 底部 Tab Bar 導航
- 滑動手勢支援

### 2.3 平板/iPad 模式

- 左側邊欄折疊式導航
- 支援觸控和滑鼠操作

### 2.4 TV Tab 順序可調整

```dart
// 設定頁儲存的 Tab 順序
class TabOrderSettings {
  List<TabItem> enabledTabs;  // 已啟用的 Tab
  bool showLive;              // 顯示直播
  bool showSearch;            // 顯示搜尋
  bool showFavorites;         // 顯示收藏
  bool showHistory;           // 顯示歷史
}
```

## 3. 首頁佈局

### 3.1 TV 首頁結構

由上而下分為以下區塊：

| 區塊 | 內容 | 高度 |
|------|------|------|
| **最近觀看** | 橫向滾動卡片列（延續觀看） | 120px |
| **直播入口** | 點擊進入直播項目頁面 | 100px |
| **分類內容** | 電影/劇集/動漫/綜藝等橫向滾動 | 200px |
| **為你推薦** | AI 推薦內容，橫向滾動 | 200px |
| **熱門電影** | 橫向滾動海報卡片 | 200px |

### 3.2 區塊可隱藏

用戶可在設定中開關各區塊顯示。

### 3.3 影視海報卡片設計

## 4. 搜尋功能

### 4.1 搜尋流程

1. 用戶輸入關鍵字 → 即時搜尋 LunaTV API
2. 結果按類型分類：全部 → 電影 → 劇集 → 動漫 → 綜藝
3. 各來源結果以標籤提示（不单独列出來源）

### 4.2 設備搜尋方式

| 設備 | 搜尋方式 |
|------|----------|
| **TV** | 遙控器按搜尋鍵 → 彈出搜尋框 → 顯示搜尋歷史 → 語音/輸入即時搜尋 |
| **Mobile** | 點擊搜尋 Tab → 輸入/語音 → 即時顯示結果 |

### 4.3 TV 搜尋佈局

```
┌──────────────────────────────────────────────────┐
│  🔍 輸入搜尋關鍵字...           [🎤] [取消]       │
├──────────────────────────────────────────────────┤
│  [全部] [電影] [劇集] [動漫] [綜藝]   ← 類型篩選   │
├──────────────────────────────────────────────────┤
│  搜尋結果                                          │
│  ┌────┐ ┌────┐ ┌────┐ ┌────┐                    │
│  │    │ │    │ │    │ │    │  ← 海報卡片         │
│  │海報│ │海報│ │海報│ │海報│    顯示來源標籤      │
│  └────┘ └────┘ └────┘ └────┘                    │
└──────────────────────────────────────────────────┘
```

### 4.4 語音搜尋

支援麥克風語音輸入，轉換為文字後自動搜尋。

## 15. TV 遙控器按鍵對應

| **Back** | 返回上一頁/關閉對話框 |

| **OK** | 確認/選擇 |

### 16.2 播放器按鍵

| 按鍵 | 動作 |
|------|------|
| **Play/Pause** | 播放或暫停 |
| **Fast Forward** | 快進（按一次 10 秒） |
| **Rewind** | 快退（按一次 10 秒） |
| **Next** | 下一集 |
| **Previous** | 上一集 |
| **Volume +/-** | 音量調節 |
| **Mute** | 靜音切換 |
| **Info** | 顯示/隱藏播放資訊 |
| **Menu** | 開啟/關閉播放器選項選單 |
| **Source** | 快速切換來源 |

**長按行為**：
| 按鍵 | 長按動作 |
|------|----------|
| **快進** | 持續快進（5x, 10x, 20x） |
| **快退** | 持續快退 |
| **上一集** | 上一集（鬆手停止） |

| 按鍵 | 動作 |

**搜尋頁**：
| 按鍵 | 動作 |
