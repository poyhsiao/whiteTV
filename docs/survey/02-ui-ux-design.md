# whiteTV — UI/UX 設計文件

**專案**: whiteTV 跨平台影視串流客戶端
**文件狀態**: v1.0 — UI/UX 詳細設計
**最後更新**: 2026-05-19

---

## 1. 設計原則

### 1.1 核心原則

| 原則 | 說明 |
|------|------|
| **10-Foot UI (TV)** | 從沙發到電視的觀看距離通常 3-5 公尺，UI 元素需足夠大、高對比、間距充足 |
| **內容優先** | 海報/縮圖先行，文字裝飾最小化 |
| **快速到達** | 用戶應能在 3 次點擊內到達任何內容 |
| **跨平台一致** | 同一 codebase，不同平台共用相同視覺語言 |
| **離散設計** | TV 遙控器操作需要明確的 Focus ring 和狀態回饋 |

### 1.2 平台特性差異

| 特性 | Android TV | iOS/tvOS | Android Mobile | iOS Mobile | macOS | Web |
|------|-----------|----------|----------------|------------|-------|-----|
| 螢幕尺寸 | 1920x1080~4K | 1920x1080~4K | 360x780~430x932 | 390x844~476x1024 | 1280x800~ | 任意 |
| 操作方式 | D-pad 遙控 | D-pad 遙控/觸控 Siri Remote | 觸控滑動 | 觸控 | 鍵盤/觸控/滑鼠 | 鍵盤/滑鼠/觸控 |
| 導航深度 | ≤3 層 | ≤3 層 | 深的巢狀導航常見 | 深的巢狀導航常見 | 中等 | 深的巢狀導航常見 |
| Focus 管理 | 絕對必要 | 必要 | 不適用 | 不適用 | 可選 | 可選 |
| 離開時間 | 高 (遙控器懶惰) | 高 | 中 | 中 | 低 | 低 |

| 主題 | 適用場景 | 背板 | 主色 | 次要色 |

## 4. 導航架構

### 4.1 導航層級

```
[Tab Bar / Sidebar — Level 0]
│
├── 首頁 (Home)
│   └── [Hero Banner — Level 1]
│       └── 詳情頁 (Detail) — Level 2
│           └── 播放器 (Player) — Level 3
│
├── 電影 (Movies)
│   └── 電影網格 — Level 1
│       └── 詳情頁 — Level 2
│           └── 播放器 — Level 3
│
├── 劇集 (TV Shows)
│   └── 季/集列表 — Level 2
│       └── 播放器 — Level 3
│
├── 動漫 (Anime) — Bangumi
│
├── IPTV (Live TV)
│   └── 頻道列表 — Level 1
│       └── 播放器 — Level 2
│
├── 收藏 (Favorites)
│   ├── 收藏的電影
│   ├── 收藏的劇集
│   └── 觀看歷史
│
└── 設定 (Settings)
    ├── 帳戶
    ├── 播放設定
    ├── 主題
    └── 關於
```

### 4.2 TV D-pad 導航行為

| 按鍵 | 行為 |
|------|------|
| **↑** | 上一個分類 (Row) / 滾動上一頁 |
| **↓** | 下一個分類 (Row) / 滾動下一頁 |
| **←** | 上一個卡片 (在同列內) |
| **→** | 下一個卡片 (在同列內) |
| **Enter** | 確認/選擇 |
| **Back/ESC** | 返回上一頁 |
| **Home** | 返回首頁 |
| **Menu** | 開啟內容選項 (更多按鈕) |

**Focus 環繞**:
- 到達列首再按 ← 時，應移動到前一列的同column位置
- 到達列尾再按 → 時，應移動到下一列的同column位置

### 4.3 手機觸控手勢

| 手勢 | 行為 |
|------|------|
| 水平滑動 | 上一頁/下一頁 (在詳情頁) |
| 垂直滑動 | 滾動內容 |
| 點擊卡片 | 進入詳情 |
| 長按卡片 | 快速收藏/加入願望清單 |
| 雙擊播放器 | 全螢幕切換 |
| 兩指縮放 | 播放器縮放 (如有支援) |

## 8. 動畫與過渡設計

### 8.1 全域動畫原則

| 屬性 | 數值 |
|------|------|
| 標準過渡 | 200ms ease-out |
| 快速過渡 | 100ms ease-out |
| 緩慢過渡 | 300ms ease-in-out |
| 彈性動畫 | 400ms cubic-bezier(0.34, 1.56, 0.64, 1) |
| 頁面過渡 | 250ms fade + slide |
| Focus 動畫 | 150ms scale + shadow |

### 8.2 Focus 動畫 (TV)

```
卡片 Focus (從 Default 到 Focused):

Default:  scale: 1.0, shadow: none
          ↓ (150ms ease-out)
Focused:  scale: 1.1
          shadow: 0 0 0 3px #6366F1
          shadow: 0 8px 16px rgba(99,102,241,0.3)

離開 Focus:
Focused → Default:  scale: 1.0, shadow: none (100ms)
```

### 8.3 頁面過渡

```
[從 A 頁面到 B 頁面]

TV/iOS:
  當前頁: fade out + slide left (200ms)
  下一頁: fade in + slide from right (200ms)
  返回:   fade out + slide right + 下一頁 slide from left

Mobile:
  頁面: slide right/left (250ms)
  Modal: slide up from bottom (300ms)
```

### 8.4 載入動畫

| 元素 | 動畫 |
|------|------|
| 頁面初次載入 | 漸層出現 (fade in, 300ms) |
| 骨架屏 | Shimmer 動畫 (漸層來回飄動) |
| 圖片載入 | Blur placeholder → 清晰圖片 (200ms) |
| 搜尋 | Spinner (圓形旋轉) |

### 8.5 手勢反饋 (Mobile)

| 手勢 | 反饋 |
|------|------|
| 按下按鈕 | scale: 0.95, 50ms |
| 釋放按鈕 | scale: 1.0, 100ms |
| 滑動列表 | 慣性滾動 + 邊界彈跳 |
| 下拉刷新 | 圓形進度指示器 |

| **Focus 可見性** | 3px primary color ring，8px 外發光 |

| **文字大小** | 最小 18sp (TV) |
| **語音導覽** | 遙控器聚焦時朗讀內容名稱 |
| **按鍵操作** | 所有功能可僅用 D-pad 完成 |

### 9.2 顏色無障礙

| 情況 | 解決方案 |
|------|---------|
| 紅/綠色盲 | 不以顏色區分重要資訊，加入圖示/文字 |
| 高對比模式 | 提供純文字標籤 (評分、狀態) |

### 9.3 螢幕閱讀器 (Mobile)

- 所有圖片有 `alt` 文字
- 按鈕有 `accessibilityLabel`
- 列表項目可被朗讀

## 14. 響應式斷點 (Responsive Breakpoints)

### 14.1 斷點定義

| 名稱 | 寬度 | 設備 |
|------|------|------|
| `xs` | 0-479px | 小型手機 |
| `sm` | 480-767px | 大型手機 |
| `md` | 768-1023px | 平板 |
| `lg` | 1024-1279px | 小型桌面 |
| `xl` | 1280-1919px | 桌面 |
| `2xl` | 1920px+ | 大型螢幕/TV |

### 14.2 每斷點的布局變化

| 斷點 | 網格列數 | 卡片寬度 | 顯示資訊 |
|------|---------|---------|---------|
| `xs` | 2 列 | 50% | 名稱 + 年份 |
| `sm` | 2-3 列 | 33-50% | 名稱 + 年份 + 評分 |
| `md` | 3-4 列 | 25-33% | 名稱 + 年份 + 評分 + 類型 |
| `lg` | 5-6 列 | 16-20% | 完整資訊 |
| `xl` | 6-8 列 | 12-16% | 完整資訊 |
| `2xl` (TV) | 8-12 列 | 8-12% | 完整資訊 |

### 14.3 TV 特定

TV 統一使用 `2xl` 斷點，但根據電視尺寸分為：
- 1080p TV: 每列 6-8 個卡片
- 4K TV: 每列 8-12 個卡片 (像素密度 2x)
